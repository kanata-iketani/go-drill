# lesson24 ch02 演習: errors.New と return err（raise の代替は return）

1 行目に整数 a と b が空白区切りで入力されます。`(int, error)` を返す関数 `divide(a, b int)` を定義し、b が 0 のときは `errors.New("0 では割れません")` をエラーとして返してください。main では err が nil でなければエラーメッセージを、成功なら a÷b の結果を出力します。

**入力される値**

```text
a b
```

**入力例1**

```text
10 2
```

**期待出力1**

```text
5
```

## テストケース

### ケース 1

入力:

```text
10 2
```

期待出力:

```text
5
```

### ケース 2

入力:

```text
7 0
```

期待出力:

```text
0 では割れません
```

### ケース 3

入力:

```text
9 3
```

期待出力:

```text
3
```
