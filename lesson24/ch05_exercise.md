# lesson24 ch05 演習: panic と recover（本当に使う場面は少ない）

1 行目に整数 n が入力されます。n が負なら `負の数は扱えません` というメッセージで panic する関数 `check(n int) int`（正常時は n×10 を返す）を用意しました。main で recover する defer を仕掛けてから `check(n)` の結果を出力し、最後に `正常に終了しました` と出力してください。panic が起きた場合は defer だけが走り、`recover: 負の数は扱えません` の 1 行になります。

**入力される値**

```text
n
```

**入力例1**

```text
5
```

**期待出力1**

```text
50
正常に終了しました
```

## テストケース

### ケース 1

入力:

```text
5
```

期待出力:

```text
50
正常に終了しました
```

### ケース 2

入力:

```text
-3
```

期待出力:

```text
recover: 負の数は扱えません
```

### ケース 3

入力:

```text
0
```

期待出力:

```text
0
正常に終了しました
```
