# lesson24 ch04 演習: 独自エラー型（Error() string を実装）

1 行目に年齢（整数）が入力されます。フィールド `Age` を持つ構造体 `AgeError` に `Error() string` を実装して独自エラー型を作り、`<年齢>歳は成人ではありません` を返すようにしてください。さらに、20 歳未満なら `&AgeError{...}` を返す関数 `checkAge(age int) error` を定義し、main では err が nil なら `成人です`、そうでなければエラーメッセージを出力します。

**入力される値**

```text
年齢
```

**入力例1**

```text
25
```

**期待出力1**

```text
成人です
```

## テストケース

### ケース 1

入力:

```text
25
```

期待出力:

```text
成人です
```

### ケース 2

入力:

```text
5
```

期待出力:

```text
5歳は成人ではありません
```

### ケース 3

入力:

```text
19
```

期待出力:

```text
19歳は成人ではありません
```
