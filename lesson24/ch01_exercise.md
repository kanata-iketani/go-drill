# lesson24 ch01 演習: Go に例外はない（error は戻り値）

1 行目に文字列が 1 つ入力されます。`strconv.Atoi` で整数への変換を試み、失敗（`err != nil`）なら `数値ではありません`、成功なら値を 2 倍した数を出力してください。try/except で捕まえるのではなく、戻り値の err を if で確かめるのが Go 流です。

**入力される値**

```text
文字列
```

**入力例1**

```text
21
```

**期待出力1**

```text
42
```

## テストケース

### ケース 1

入力:

```text
21
```

期待出力:

```text
42
```

### ケース 2

入力:

```text
abc
```

期待出力:

```text
数値ではありません
```

### ケース 3

入力:

```text
100
```

期待出力:

```text
200
```
