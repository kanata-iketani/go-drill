# lesson20 ch05 演習: 再帰

1 行目に整数 n（0〜12）が与えられます。
**再帰**で階乗を計算する関数 `fact(n int) int` を定義し、`fact(n)` を出力してください。
for 文は使わず、基底条件（n == 0 のとき 1）と自分自身の呼び出しで書いてください。

**入力例1**

```text
5
```

**期待出力1**

```text
120
```

## テストケース

### ケース 1

入力:

```text
5
```

期待出力:

```text
120
```

### ケース 2

入力:

```text
0
```

期待出力:

```text
1
```

### ケース 3

入力:

```text
10
```

期待出力:

```text
3628800
```
