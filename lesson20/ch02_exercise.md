# lesson20 ch02 演習: ポインタ渡し（*int と &）

1 行目に整数 x が与えられます。
指した先を 2 倍にする関数 `double(p *int)` を定義し、`double(&x)` を 2 回呼んで、
1 回目の後の x と 2 回目の後の x を 1 行ずつ出力してください。

**入力例1**

```text
5
```

**期待出力1**

```text
10
20
```

## テストケース

### ケース 1

入力:

```text
5
```

期待出力:

```text
10
20
```

### ケース 2

入力:

```text
7
```

期待出力:

```text
14
28
```

### ケース 3

入力:

```text
0
```

期待出力:

```text
0
0
```
