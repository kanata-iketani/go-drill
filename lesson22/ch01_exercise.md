# lesson22 ch01 演習: Go に継承はない（is-a ではなく has-a で考える）

1 行目に名前、2 行目に会社名が入力されます。名前を持つ構造体 `Person` と、`Person` をフィールドとして持つ（has-a）構造体 `Employee` を使って、`<名前> は <会社名> の社員です` と 1 行出力してください。継承の代わりに `Employee` が `Person` を「持ち」、名前には `e.Person.Name` の形でアクセスするのがポイントです。

**入力される値**

```text
名前
会社名
```

**入力例1**

```text
田中
ペイザ株式会社
```

**期待出力1**

```text
田中 は ペイザ株式会社 の社員です
```
