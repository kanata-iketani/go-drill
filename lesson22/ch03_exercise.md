# lesson22 ch03 演習: インターフェース（振る舞いの契約と暗黙実装）

1 行目に動物の種類（`dog` か `cat`）と名前が空白区切りで入力されます。インターフェース `Speaker` 型の変数 `s` に、種類が `dog` なら `Dog`、`cat` なら `Cat` の値を代入し、`s.Speak()` の結果を 1 行出力してください。どちらの型も `Speak() string` を持つため、宣言を書かなくても `Speaker` を満たしています（暗黙実装）。

**入力される値**

```text
種類 名前
```

**入力例1**

```text
dog ポチ
```

**期待出力1**

```text
ポチ: ワン
```

## テストケース

### ケース 1

入力:

```text
dog ポチ
```

期待出力:

```text
ポチ: ワン
```

### ケース 2

入力:

```text
cat タマ
```

期待出力:

```text
タマ: ニャー
```

### ケース 3

入力:

```text
dog コロ
```

期待出力:

```text
コロ: ワン
```
