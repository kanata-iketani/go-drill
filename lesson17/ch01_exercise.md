# lesson17 ch01 演習: Go に set 型は存在しない（map で代用する）

スターターには会員名簿の集合 `members` が定義されています。標準入力から名前が 1 行で与えられるので、名簿にあれば `OK`、なければ `NG` と出力してください。

**入力される値**

```text
名前
```

**入力例1**

```text
sato
```

**期待出力1**

```text
OK
```

## テストケース

### ケース 1

入力:

```text
sato
```

期待出力:

```text
OK
```

### ケース 2

入力:

```text
yamada
```

期待出力:

```text
NG
```

### ケース 3

入力:

```text
tanaka
```

期待出力:

```text
OK
```
