# Lesson 04 変数

Go の変数は型が固定で、宣言していない変数への代入はできず、使っていない変数が残っているだけでビルドエラーになります。

## ch01 var による宣言

Go で変数を作る基本形は `var 変数名 型 = 値` です。**宣言**（この名前の変数をこの型で使うとコンパイラに伝えること）が必須な点が Python との大きな違いです。初期値から型が明らかなときは `var name = "gopher"` と型を省略できます。値を入れずに `var count int` と宣言すると、**ゼロ値**（型ごとの初期値。int は 0、string は ""）が入ります。🟡 「宣言してから使う」を理解しましょう。

Python ではこう書いた:

```python
name = "gopher"
```

Go ではこう書く:

```go
var name string = "gopher"
```

## ch02 := による短縮宣言

関数の中では `name := "gopher"` と書くだけで、宣言と代入を同時にできます。型は右辺から自動で決まります（型推論）。見た目は Python の代入とほぼ同じですが、`:=` は「新しい変数を作る」記号であり、作った変数の型はやはり固定です。実際の Go のコードでは var よりこちらが主流です。🔴 `:=` は今後全レッスンで使うので、手が覚えるまで書きましょう。

Python ではこう書いた:

```python
age = 20
```

Go ではこう書く:

```go
age := 20 // int と推論される
```

## ch03 再代入と未使用変数エラー

一度作った変数に値を入れ直すときは `=` を使います（`:=` ではない点に注意）。型が固定なので、int の変数に文字列を再代入することはできません。もう 1 つ Python にない特徴として、宣言したのに一度も使わない変数はビルドエラーになります。「消し忘れの変数はバグのもと」という思想で、コンパイラが強制的に掃除させます。🟡 `:=` と `=` の使い分けを理屈で押さえましょう。

Python ではこう書いた:

```python
score = 80
score = "high"  # 型が変わっても平気
unused = 1      # 使わなくても何も起きない
```

Go ではこう書く:

```go
score := 80
score = 90        // 再代入は = （同じ int のみ）
// unused := 1    // 使わないとビルドエラー: declared and not used
```
