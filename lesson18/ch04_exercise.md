# lesson18 ch04 演習: 無名関数（lambda の代わり）

1 行目に整数 n が与えられます。
2 乗を返す**無名関数**を変数 `square` に代入し（`square := func(x int) int { ... }` の形）、
`square(n)` と `square(n+1)` の結果を 1 行ずつ出力してください。

**入力例1**

```text
3
```

**期待出力1**

```text
9
16
```

## テストケース

### ケース 1

入力:

```text
3
```

期待出力:

```text
9
16
```

### ケース 2

入力:

```text
5
```

期待出力:

```text
25
36
```

### ケース 3

入力:

```text
0
```

期待出力:

```text
0
1
```
