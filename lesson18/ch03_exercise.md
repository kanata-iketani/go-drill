# lesson18 ch03 演習: 多値を返す関数

1 行目に整数 a と b（b は 0 以外）が空白区切りで与えられます。
商と余りの **2 つの値を返す**関数 `divide(a, b int) (int, int)` を定義し、
商と余りをこの順に空白区切りで 1 行に出力してください（`fmt.Println(q, r)` で出力できます）。

**入力例1**

```text
17 5
```

**期待出力1**

```text
3 2
```

## テストケース

### ケース 1

入力:

```text
17 5
```

期待出力:

```text
3 2
```

### ケース 2

入力:

```text
20 4
```

期待出力:

```text
5 0
```

### ケース 3

入力:

```text
7 10
```

期待出力:

```text
0 7
```
