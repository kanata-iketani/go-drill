# lesson19 ch03 演習: パッケージ変数（global 文はない）

口座の残高を管理します。1 行目に取引額（正なら入金、負なら出金）が空白区切りで 1 個以上与えられます。
**パッケージ変数** `var balance = 1000` と、balance に n を足す関数 `apply(n int)` を定義し、
取引を順に apply してから最終残高を出力してください（`global` に当たる宣言は書かないこと）。

**入力例1**

```text
100 -30
```

**期待出力1**

```text
1070
```
