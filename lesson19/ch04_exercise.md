# lesson19 ch04 演習: := が作る意図しない新変数

整数が 1 行に 1 つずつ、複数行にわたって与えられます（行数は決まっていません）。
`for sc.Scan() { ... }` で全行を読み、各行を
`if n, err := strconv.Atoi(sc.Text()); err == nil { ... }` の形で変換して、
**if の中で** total に足してください。最後に total を出力します。
（n と err は if の外では使えないことを確かめながら書いてください）

**入力例1**

```text
3
4
```

**期待出力1**

```text
7
```
