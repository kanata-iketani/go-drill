# lesson19 ch02 演習: シャドーイング

1 行目に整数 x が与えられます。次の 2 行を出力するプログラムを書いてください。

1. `{}` ブロックの中で `x := x * 10` と**同名の変数を宣言**して、その値を出力
2. ブロックを出た後に、外側の `x` を出力（元の値のままであることを確認する）

**入力例1**

```text
5
```

**期待出力1**

```text
50
5
```

## テストケース

### ケース 1

入力:

```text
5
```

期待出力:

```text
50
5
```

### ケース 2

入力:

```text
3
```

期待出力:

```text
30
3
```

### ケース 3

入力:

```text
12
```

期待出力:

```text
120
12
```
