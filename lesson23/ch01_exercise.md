# lesson23 ch01 演習: package と main が入口

1 行目に名前が入力されます。`こんにちは、<名前> さん` という文字列を返す関数 `greet(name string) string` を main の外に定義し、main から呼び出して結果を出力してください。greet は main から呼ばれてはじめて動きます。`if __name__ == "__main__"` のようなガードは書きません。

**入力される値**

```text
名前
```

**入力例1**

```text
田中
```

**期待出力1**

```text
こんにちは、田中 さん
```
