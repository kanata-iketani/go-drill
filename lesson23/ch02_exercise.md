# lesson23 ch02 演習: import と標準ライブラリ（math・os など）

1 行目に整数 a と b が空白区切りで入力されます。`math` パッケージを import して、1 行目に a の b 乗（`math.Pow`）、2 行目に a と b の大きい方（`math.Max`）を整数で出力してください。math の関数は float64 を受け渡しするため、`float64(a)` に変換して渡し、結果を `int(...)` に戻すのがポイントです。

**入力される値**

```text
a b
```

**入力例1**

```text
2 10
```

**期待出力1**

```text
1024
10
```

## テストケース

### ケース 1

入力:

```text
2 10
```

期待出力:

```text
1024
10
```

### ケース 2

入力:

```text
3 4
```

期待出力:

```text
81
4
```

### ケース 3

入力:

```text
5 3
```

期待出力:

