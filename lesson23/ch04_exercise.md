# lesson23 ch04 演習: init()（main より先に走る初期化関数）

1 行目に名前が入力されます。`設定を読み込みました` と出力する `init()` を定義し、main では `ようこそ、<名前> さん` と出力してください。init は呼び出しコードを書かなくても main より先に実行されるため、出力は必ず「設定を読み込みました」が先になります。

**入力される値**

```text
名前
```

**入力例1**

```text
田中
```

**期待出力1**

```text
設定を読み込みました
ようこそ、田中 さん
```
