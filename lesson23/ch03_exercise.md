# lesson23 ch03 演習: go mod init と複数ファイル

1 行目に個数 n、2 行目に n 個の整数が空白区切りで入力されます。合計を返す関数 `sum(nums []int) int` と最大値を返す関数 `maxOf(nums []int) int` を main の外（トップレベル）に定義し、1 行目に合計、2 行目に最大値を出力してください。トップレベルの関数は、同じ `package main` なら別ファイル（例: calc.go）に移しても import なしで呼べる形です。

**入力される値**

```text
n
a1 a2 ... an
```

**入力例1**

```text
3
1 2 3
```

**期待出力1**

```text
6
3
```
