# Lesson 10 条件分岐

Go の `if` は条件に括弧を付けず、ブロックの `{}` を省略できません。`elif` は `else if` になり、`pass` の代わりは空ブロック `{}` です。

## ch01 if（条件に括弧なし・{} は必須）

Go の `if` は「条件が真のときだけ実行する」という意味は Python と同じですが、書き方が 2 点違います。第一に、条件を囲む括弧 `()` は書きません。第二に、ブロックはインデントではなく波括弧 `{}` で表し、処理が 1 行でも必ず `{}` を付けます。また Python の `pass`（何もしないことを示す文）に相当する語はなく、何もしないときは空ブロック `{}` を書きます。🔴 if は今後のすべてのコードで使うので、この形を手が覚えるまで書きましょう。

Python ではこう書いた:

```python
if x > 10:
    print("大きい")
```

Go ではこう書く:

```go
if x > 10 {
	fmt.Println("大きい")
}
```

## ch02 else if と else（elif の代わり）

複数の条件で分岐するとき、Python の `elif` は Go では `else if` と 2 語で書きます。`else` はそのままです。注意点は書く位置で、`else if` も `else` も直前の閉じ波括弧 `}` と同じ行に書きます。行を分けるとコンパイルエラーになります。条件に括弧を付けない点、`{}` を省略できない点は if と同じです。🔴 分岐は頻出なので、`} else if 条件 {` のつながりごと手が覚えるまで書きましょう。

Python ではこう書いた:

```python
if score >= 80:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
```

Go ではこう書く:

```go
if score >= 80 {
	fmt.Println("A")
} else if score >= 60 {
	fmt.Println("B")
} else {
	fmt.Println("C")
}
```

## ch03 条件の前の1文（if v := f(); v > 0）

Go の `if` は、条件の前にセミコロン `;` で区切って 1 文を書けます。「値を作って、すぐ判定する」ための形で、ここで宣言した変数はこの if と else の中だけで有効です。Python に対応する構文はなく、代入と if の 2 行に分けて書いていました。この形は後に学ぶエラー処理 `if err := ...; err != nil {` で多用される、Go らしい書き方です。🟡 まずは形と、変数が if の外では使えないという理屈を理解しましょう。

Python ではこう書いた:

```python
l = len(word)
if l >= 5:
    print("長い単語")
```

Go ではこう書く:

```go
if l := len(word); l >= 5 {
	fmt.Println("長い単語")
}
```
