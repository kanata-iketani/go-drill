# lesson15 ch02 演習: 読んだ文字列を数値へ（strconv.Atoi）

標準入力から年齢（整数）が 1 行で与えられます。`strconv.Atoi` で数値に変換し、`来年は{年齢+1}歳です` の形式で出力してください。

**入力される値**

```text
年齢
```

**入力例1**

```text
20
```

**期待出力1**

```text
来年は21歳です
```

## テストケース

### ケース 1

入力:

```text
20
```

期待出力:

```text
来年は21歳です
```

### ケース 2

入力:

```text
7
```

期待出力:

```text
来年は8歳です
```

### ケース 3

入力:

```text
99
```

期待出力:

```text
来年は100歳です
```
