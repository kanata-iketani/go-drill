# lesson25 ch02 演習: スライスとマップが「参照的」に振る舞う理由

1 行目に個数 n、2 行目に n 個の整数が空白区切りで入力され、スターターでスライス `a` に格納済みです。`b := a` と代入してから `b[0]` を 10 倍し、1 行目に `a`、2 行目に `b` を `fmt.Println` でそのまま出力してください。コピーされるのはヘッダだけで中身の配列は共有されているため、2 行は同じ内容になります。

**入力される値**

```text
n
a1 a2 ... an
```

**入力例1**

```text
3
1 2 3
```

**期待出力1**

```text
[10 2 3]
[10 2 3]
```
