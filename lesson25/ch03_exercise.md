# lesson25 ch03 演習: ポインタ（& と * で呼び出し元を変える）

1 行目に整数 n が入力されます。`*int` を受け取り指し先に 10 を足す関数 `addTen(p *int)` を定義してください。main では `x := n` としてから 1 行目に `before: <x>` を出力し、`addTen(&x)` を呼んだあと 2 行目に `after: <x>` を出力します。ポインタ渡しによって、関数の中の変更が呼び出し元の x に届くことを確かめる問題です。

**入力される値**

```text
n
```

**入力例1**

```text
5
```

**期待出力1**

```text
before: 5
after: 15
```

## テストケース

### ケース 1

入力:

```text
5
```

期待出力:

```text
before: 5
after: 15
```

### ケース 2

入力:

```text
100
```

期待出力:

```text
before: 100
after: 110
```

### ケース 3

入力:

```text
0
```

期待出力:

```text
before: 0
after: 10
```
