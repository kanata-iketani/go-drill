# lesson16 ch03 演習: カンマ ok イディオム v, ok := m[k]

スターターにはメニュー表 `menu` が定義されています。標準入力から商品名が 1 行で与えられるので、メニューにあれば `{価格}円`、なければ `ありません` と出力してください。

**入力される値**

```text
商品名
```

**入力例1**

```text
coffee
```

**期待出力1**

```text
480円
```

## テストケース

### ケース 1

入力:

```text
coffee
```

期待出力:

```text
480円
```

### ケース 2

入力:

```text
juice
```

期待出力:

```text
ありません
```

### ケース 3

入力:

```text
cocoa
```

期待出力:

```text
520円
```
