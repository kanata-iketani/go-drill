# lesson16 ch04 演習: delete と len

スターターには在庫表 `stock`（3 商品）が定義されています。標準入力から商品名が 1 行で与えられるので、その商品を `delete` で削除し、削除後の要素数を出力してください。存在しない商品名が与えられることもありますが、その場合も delete を呼んで構いません。

**入力される値**

```text
削除する商品名
```

**入力例1**

```text
pen
```

**期待出力1**

```text
2
```

## テストケース

### ケース 1

入力:

```text
pen
```

期待出力:

```text
2
```

### ケース 2

入力:

```text
eraser
```

期待出力:

```text
3
```

### ケース 3

入力:

```text
clip
```

期待出力:

```text
2
```
