# lesson16 ch01 演習: map リテラルと取得

スターターには果物の価格表 `prices` が定義されています。標準入力から果物名が 1 行で与えられるので、その果物の価格を出力してください。

**入力される値**

```text
果物名（apple / banana / orange のいずれか）
```

**入力例1**

```text
apple
```

**期待出力1**

```text
120
```

## テストケース

### ケース 1

入力:

```text
apple
```

期待出力:

```text
120
```

### ケース 2

入力:

```text
orange
```

期待出力:

```text
60
```

### ケース 3

入力:

```text
banana
```

期待出力:

```text
90
```
