# Go入門ドリル

ブラウザ上でGoのコードを書いて、実行して、その場で自動採点しながら学べるローカル学習アプリです。全25レッスンで、Goの基礎（標準出力・変数・スライス・条件分岐・繰り返し・関数・構造体・インターフェース・エラー処理・ポインタなど）を、手を動かしながら身につけます。

Python など他の言語の経験がある人が「Goならどう書くか」を最短で掴めるよう、要所でPythonとの違いにも触れています。

> このドリルは「[42日でバックエンドエンジニアの基礎を完全に理解する](https://zenn.dev/kipcop)」シリーズの入門編です。本編 #1〜#4 が難しいと感じたら、まずここでGoそのものに慣れてから戻ると、ぐっと進みやすくなります。

## 動かす

Go 1.22 以降が入っていれば、追加インストールは不要です。

```sh
git clone https://github.com/kanata-iketani/go-drill.git
cd go-drill/app
go run .
```

起動したらブラウザで <http://localhost:8080> を開いてください。左に教材、右にコードエディタと実行・採点結果が出ます。

- **▶ 実行** … 書いたコードを `go run` で実行し、出力を確認します
- **✔ 採点** … 期待される出力と照合して合否を判定します（標準入力が必要な問題も自動でテストします）
- **解答を見る / リセット / 次へ** … 詰まったら模範解答を確認し、次の章へ進めます

進捗はローカルに保存されるので、途中でやめても続きから再開できます。

### AIに質問する機能（任意・既定オフ）

各章について、その場でAIに質問できる機能を用意しています。**この機能は既定でオフ**です。使うには [Claude Code CLI](https://docs.claude.com/claude-code) がローカルに入っている必要があり、有効化するときだけ起動オプションを付けます。

```sh
go run . -enable-ai
```

有効にすると学習画面の右上に「💬 質問」が現れ、今開いている章の教材・演習・自分のコードを踏まえてAIが回答します（回答はローカルのCLIをヘッドレス実行するので、APIキーの登録は不要です）。Claude Code CLI が無い環境では、オプションを付けても機能は自動的に無効のままなので、通常の学習には影響しません。

## 学習の進め方

各レッスンは複数の章でできていて、1章は次の3点セットです。

1. **説明** … 🔴🟡⚪ のマークで学習の深さの目安を示します（🔴 手が覚えるまで書く／🟡 理屈を理解する／⚪ 存在だけ知っておく）
2. **サンプルコード** … 動く例を読んで、エディタにコピーして実行できます
3. **演習** … 自分でコードを書き、採点で確かめます

コマンドラインだけで進めたい場合は、各レッスンの `README.md`・`chNN_sample.go`・`chNN_exercise.md`・`answer/` を直接読んで `go run` してもかまいません。
